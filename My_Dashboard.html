      Sync your dashboard
      Follow the steps once, then every device will stay in sync automatically.
      Step 1 — Create a free Firebase project

      Go to console.firebase.google.com → Add project → any name → Continue (disable Analytics is fine) → Create project.

      Open Firebase Console ↗
      Step 2 — Enable Realtime Database

      In your project: Build → Realtime Database → Create database → pick any location → Start in test mode → Enable.

      Step 3 — Get your config

      Click the ⚙ gear → Project Settings → scroll to Your apps → click </> (Web) → Register app → copy the firebaseConfig block → paste below.

      Acts as your password. Same passphrase = same data on all devices.
      Host with Netlify (free, 30 seconds)

      1. Go to app.netlify.com/drop
      2. Drag your My_Dashboard.html file onto the page
      3. Netlify gives you a URL like your-name.netlify.app
      4. Open that URL on your phone — done.

      Open Netlify Drop ↗
      Add to your phone's home screen

      iPhone: Open the URL in Safari → tap the Share button → Add to Home Screen.

      Android: Open in Chrome → tap the menu (⋮) → Add to Home Screen.

      Important

      Set up Firebase Sync first (the Setup tab) so data actually stays the same on both devices. Netlify only hosts the file — Firebase is what makes the data sync.
