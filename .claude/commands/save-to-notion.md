# Save to Notion (Second Brain)

Capture something to my Notion second brain.

Ask me for:
1. **Title** — short, clear
2. **Content** — the note body (can be pasted or described)
3. **Type** — choose one: Note / Idea / Goal / Book Note / Reference / Daily Log
4. **Tags** — comma-separated

Then use the Notion MCP (`mcp__Notion__notion-create-pages`) to create the page. Format the content with proper Notion blocks — use headings, bullets, and callouts where appropriate. Use Obsidian-style structure when relevant (MOC links, #tags, related pages).

Confirm the page was created and share the title back.
