# Add a New Panel

Guide me through adding a new panel to `My_Dashboard.html`. Ask me:

1. **Panel name** — what it tracks (e.g. "Sleep", "Habits", "Journal")
2. **Panel ID** — will become `panel-{id}` (e.g. `panel-sleep`)
3. **Nav icon** — which SVG icon to use in the bottom nav (suggest 3 options)
4. **Sections** — what cards/sections go inside (I'll describe, you design the markup)
5. **Data shape** — what to store in localStorage (suggest a schema)

Then implement it following the project's design system — `.page-bar`, `.sect`, `.card`, `.fstat`, etc. Use existing CSS classes before adding new ones. Add the nav entry via the `buildNav()` pattern.

After implementing: list exactly what was added and where.
